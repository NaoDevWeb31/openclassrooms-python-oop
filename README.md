# Apprenez la programmation orientée objet avec Python

Exercices et travaux pratiques réalisés dans le cadre du cours **« Apprenez la programmation orientée objet avec Python »** proposé par [OpenClassrooms](https://openclassrooms.com/fr/courses/7150616-apprenez-la-programmation-orientee-objet-avec-python).

## Objectifs du cours

- Comprendre les principes de la programmation orientée objet (POO).
- Créer et utiliser des classes et des objets en Python.
- Manipuler les attributs et les méthodes.
- Découvrir les notions d'héritage, d'encapsulation et de polymorphisme.
- Structurer et organiser du code orienté objet.

## Organisation du repository
